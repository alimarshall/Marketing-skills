## Handling conflicts and old advice

Use UI requirements for UI execution and API documentation for that API/version. For example, the current contact-list Help page distinguishes the minimum upload rows from the recommended email volume; API text can phrase volume differently. Use the live template and route-specific guidance rather than inventing a compromise.

Live interfaces can offer windows or formats not yet described in an older Help article. Record the selected live value and the discrepancy. A list category called Lookalike in a picker does not establish that discontinued lookalike creation is supported.

These links support platform mechanics. They do not prove a funnel is effective for a particular company. Use that company's controlled tests, mature cohorts and qualified CRM outcomes for commercial decisions.
